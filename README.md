# SQL Server Performance Lab

A practical laboratory for understanding and troubleshooting SQL Server performance.

## Topics

- Blocking and deadlocks
- Wait statistics
- Slow queries
- Execution plans
- Indexing
- Query Store
- Extended Events
- Parameter sensitivity
- Memory and CPU pressure
- TempDB and I/O

## Structure

- `blocking/`
- `waits/`
- `query-performance/`
- `indexing/`
- `execution-plans/`
- `query-store/`
- `extended-events/`

## Approach

Each lab should include a problem, evidence, investigation, solution and validation step.

## Disclaimer

All examples are synthetic or sanitized.
